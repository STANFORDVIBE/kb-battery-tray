# KbBatteryTray

Иконка в трее Windows с зарядом беспроводной клавиатуры на донгле **CompX 2.4G** (VID `3554` / PID `FA09`; его ставят AULA, MCHOSE, Redragon, Xinmeng и другие). Rust + чистый Win32, лёгкая, как и [R5BatteryTray](../R5BatteryTray) для мыши.

- В трее значок клавиатуры, заряд показывают клавиши: слева направо загораются зелёным (≤20% — красным), остальные серые; все серые — клавиатура ещё ни разу не ответила. На зарядке в правом верхнем углу появляется жёлтая молния. Точный % — в подсказке при наведении.
- Обновляется раз в 30 секунд и по левому клику. Если клавиатура спит, остаётся последнее значение.
- Правый клик: «Обновить», «Запускать с Windows», «Проверить обновления», «Выход». Обновление только по кнопке: виджет скачает новую версию с GitHub, подменит себя и перезапустится.

## Запуск

Скачай `KbBatteryTray.exe` из [Releases](../../releases) и запусти, установка не нужна.

## Сборка

Нужен [Rust](https://rustup.rs). `build.bat` соберёт и положит `KbBatteryTray.exe` рядом. Тесты: `cargo test`, превью иконки во всех размерах: `cargo test preview -- --ignored` (`preview.bmp`), проверка с живым донглом: `cargo test live -- --ignored --nocapture`.

Новая версия: поднять `version` в `Cargo.toml` → `build.bat` → тег `v<версия>` → релиз с файлом `KbBatteryTray.exe` (именно так, его качает обновлялка).

## Протокол

Output-репорт 20 байт в интерфейс с usage page `FF02`: запрос `13 4A 00…00 5D` (последний байт — сумма первых 19). В ответе `13 4A …`: `[5]` — процент, `[6]` — состояние (`01` батарея, бит `10` — провод). Подсмотрено в [omarchy-gadget-batteries](https://github.com/xii69/omarchy-gadget-batteries) и [wireless-battery-tray](https://github.com/kun-qaq/wireless-battery-tray).
