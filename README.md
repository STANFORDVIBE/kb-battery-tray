# KbBatteryTray

Иконка в трее Windows с зарядом беспроводной клавиатуры на донгле **CompX 2.4G** (VID `3554` / PID `FA09`; его ставят AULA, MCHOSE, Redragon, Xinmeng и другие). Rust + чистый Win32, лёгкая, как и [R5BatteryTray](../R5BatteryTray) для мыши.

- В трее значок клавиатуры, заряд показывают клавиши: слева направо загораются зелёным (≤20% — красным), остальные серые; все серые — клавиатура ещё ни разу не ответила. На зарядке в правом верхнем углу появляется жёлтая молния. Точный % — в подсказке при наведении.
- Обновляется раз в 30 секунд. Если клавиатура спит, остаётся последнее значение.
- Прогноз: в подсказке и в панели — на сколько примерно хватит заряда (или сколько до полной на проводе). Появляется, когда заряд сядет хотя бы на 2% за час (на проводе — 2% за 5 минут); считается по настоящему времени, включая сон, и запоминается в `%APPDATA%\KbBatteryTray\battery.txt`.
- Левый клик по иконке — панель настроек «вытекает» из трея, как у [R5BatteryTray](../R5BatteryTray): подсветка (вкл/выкл, 14 эффектов, яркость, скорость, цвет из палитры, радуга или свой — полосками оттенка и насыщенности) и через сколько засыпать. Всё пишется прямо в клавиатуру. Сделано по протоколу веб-драйвера AULA для F75 (на том же донгле у AULA ещё F87, F87 Pro и F99). Сворачивается, когда курсор уходит с панели, по клику мимо, Esc или повторному клику по иконке.
- Значок клавиатуры рядом с «AULA F75» в панели открывает окно с нарисованной F75: клик по клавише, затем нажать на клавиатуре клавишу или сочетание (Ctrl+C и т.п.) — или выбрать из меню: пауза/пуск, калькулятор, браузер, почта, «Этот компьютер», «Открыть программу…» (любой файл или ярлык; клавиатура шлёт редкую F13–F24, виджет её ловит и открывает файл — работает, пока виджет запущен, список в `launch.txt`), «Отключить клавишу», «Как было». Два слоя: обычный и с зажатой Fn. Раскладка пишется в саму клавиатуру; Fn и заводские функции (★) не трогаются.
- Перед первой правкой виджет сохраняет настройки клавиатуры в `%APPDATA%\KbBatteryTray\backup.bin` (палитры — в `backup-colors.bin`, раскладку — в `backup-keys.bin`); вернуть их — «Вернуть настройки как до виджета…» в меню или «Вернуть всю раскладку как было» в окне клавиш.
- Правый клик: «Обновить», «Запускать с Windows», «Проверить обновления», «Выход». Обновление только по кнопке: виджет скачает новую версию с GitHub, проверит подпись автора, подменит себя и перезапустится. Неподписанное или подменённое обновление не ставится.

## Запуск

Скачай `KbBatteryTray.exe` из [Releases](../../releases) и запусти, установка не нужна.

## Сборка

Нужен [Rust](https://rustup.rs). `build.bat` соберёт и положит `KbBatteryTray.exe` рядом. Тесты: `cargo test`, превью иконки во всех размерах: `cargo test preview -- --ignored` (`preview.bmp`), чтение с живой клавиатуры: `cargo test read_live -- --ignored --nocapture`, запись с возвратом как было: `cargo test write_live -- --ignored --nocapture`, панель без клавиатуры (подставные данные): отладочная сборка с переменной `KB_FAKE=1`.

Новая версия: поднять `version` в `Cargo.toml` → `build.bat` → `scripts\sign-release.ps1` → тег `v<версия>` → релиз с файлами `KbBatteryTray.exe` и `KbBatteryTray.exe.sig` (именно так, их качает обновлялка). Закрытый ключ лежит в `%USERPROFILE%\.kbbatterytray\release.key`, зашифрованный паролем (скрипт спрашивает его при подписи). Держи копию файла: без него и пароля обновления по кнопке не выпустить.

## Протокол

Output-репорт 20 байт в интерфейс с usage page `FF02`: запрос `13 4A 00…00 5D` (последний байт — сумма первых 19). В ответе `13 4A …`: `[5]` — процент, `[6]` — состояние (`01` батарея, бит `10` — провод). Настройки — таблица 140 байт: `0x44` читает, `0x04` пишет целиком, `0x49` читает палитры, `0x09` пишет их (свой цвет — первым цветом палитры эффекта, как в драйвере). Подробности в `src/kb.rs`. Подсмотрено в [omarchy-gadget-batteries](https://github.com/xii69/omarchy-gadget-batteries) и [wireless-battery-tray](https://github.com/kun-qaq/wireless-battery-tray).
