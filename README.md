# KbBatteryTray

Иконка в трее Windows с зарядом беспроводной клавиатуры на донгле **CompX 2.4G** (VID `3554` / PID `FA09`; его ставят AULA, MCHOSE, Redragon, Xinmeng и другие). Rust + чистый Win32, лёгкая, как и [R5BatteryTray](../R5BatteryTray) для мыши.

- В трее батарейка с голубым контуром (у мышиной он белый), заполненная по заряду. Цвета: зелёная — норм, красная — ≤20%, жёлтая — заряжается, пустая — клавиатура ещё ни разу не ответила. Точный % — в подсказке при наведении.
- Обновляется раз в 30 секунд и по левому клику. Если клавиатура спит, остаётся последнее значение.
- Правый клик: «Обновить», «Запускать с Windows», «Выход».

## Запуск

Запусти `KbBatteryTray.exe`, установка не нужна.

## Сборка

Нужен [Rust](https://rustup.rs). `build.bat` соберёт и положит `KbBatteryTray.exe` рядом. Тесты: `cargo test`, проверка с живым донглом: `cargo test -- --ignored --nocapture`.

## Протокол

Output-репорт 20 байт в интерфейс с usage page `FF02`: запрос `13 4A 00…00 5D` (последний байт — сумма первых 19). В ответе `13 4A …`: `[5]` — процент, `[6]` — состояние (`01` батарея, `10` провод). Подсмотрено в [omarchy-gadget-batteries](https://github.com/xii69/omarchy-gadget-batteries) и [wireless-battery-tray](https://github.com/kun-qaq/wireless-battery-tray).
